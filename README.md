# 人權辦桌｜募資商品製圖修改器

2026 第十一屆人權辦桌嘖嘖募資的商品介紹圖編輯工具。編輯可以改文字、價格和背景色，版面位置固定，改完匯出 PNG。

## 上傳到 GitHub Pages

1. 在 GitHub 建立一個新的 repository（公開或私人都可以；私人 repo 需要付費方案才能開 Pages）。
2. 把這個資料夾裡的**所有檔案和子資料夾**原樣上傳（`index.html` 要在最上層）。網頁上傳時可以直接把整個資料夾拖進「Add file › Upload files」。
3. 到 repository 的 **Settings › Pages**，Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，頁面上方會出現網址（`https://<帳號>.github.io/<repo 名稱>/`），把這個網址給編輯就好。

> 不能直接雙擊 `index.html` 開啟，一定要透過網址（GitHub Pages 或任何網頁伺服器）才會正常顯示。

## 編輯怎麼用

1. 點上方的卡片按鈕（A01、B01、C01…）選要改的那張。
2. 在右側面板改商品名稱、副標、價格、規格、組合或回饋內容、參與意義，以及背景色。每欄都有字數上限，避免跑版。
3. 按「匯出 PNG 1000 × 563」或「2000 × 1126」下載圖片。
4. 修改只會存在**自己這台電腦的瀏覽器**，其他人看不到；換電腦或清除瀏覽器資料就會回到預設內容。
5. 「進階設定」是設計者用的（視角、裝飾、審稿標記、替換圖片），一般編輯不用打開。

## 要改預設內容

打開 `index.html`，搜尋 `const DEFAULTS`，每張卡的預設文字、價格、背景色都在那裡。改完重新上傳即可。審稿狀態分頁的資料在 `review-data.js`。

## 檔案說明

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 主頁面（商品介紹圖、視覺系統、Mockup、審稿狀態） |
| `Mockup.dc.html` | 商品 Mockup 元件 |
| `support.js` | 頁面執行環境 |
| `review-data.js` | 素材盤點、待確認清單、15 張規劃表 |
| `assets/` | 圖片（已轉成 WebP 並縮到需要的大小） |
| `fonts/` | 饅頭黑體、jf open 粉圓 2.1、思源黑體 TC（已縮減字集） |
| `vendor/` | React 18.3.1、html-to-image 1.11.11（本地版本，不依賴外部 CDN） |

## 關於字體

為了縮小檔案，三套字體只保留 Big5 常用字（5,401 字）、標點、注音、拉丁字母與台羅拼音符號，以及頁面上目前用到的所有字。編輯若輸入罕用字，該字會以電腦內建字體顯示；頁首的「饅頭黑體缺字檢查」會列出缺字。
